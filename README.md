# NRC Half Marathon Tracker

Track your progress through Nike Run Club's **14-week Audio Guided Half Marathon Training Plan**.

## Features

- Full 14-week schedule (recovery, speed, and long runs from the official PDF)
- Pace chart with personalized targets
- Log runs (distance, time, pace, feeling, notes)
- Mark workouts complete and see weekly progress
- Race day countdown

## Quick start

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Official plan

[Nike Run Club Half Marathon Training Plan (PDF)](https://www.nike.com/pdf/Nike-Run-Club-Half-Marathon-Training-Plan-Audio-Guided-Runs.pdf)

A copy is included at `public/plan.pdf`.

## Data

All data is stored in your browser (`localStorage`). Nothing is sent to a server.
